# OpsFlow API

Lightweight **JSON Server** REST API for the OpsFlow POC.

> The POC uses a lightweight JSON Server REST API to keep the
> implementation focused on frontend and mobile engineering. The clients
> communicate through a REST API contract, allowing the data layer to be
> replaced with a production backend later.

This is **not** a production backend.

---

## Quick start

From the repository root:

```bash
npm install
npm run api:seed    # regenerate db.json (deterministic)
npm run api         # http://localhost:3001
```

From `api/`:

```bash
npm run seed
npm start
```

Default base URL (shared constant): `http://localhost:3001`

Hosted (Render): `npm run start:prod` → `server.mjs` (uses `PORT`, no `--watch`). See [docs/DEPLOYMENT.md](../docs/DEPLOYMENT.md).

## Resources & endpoints

### Jobs

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/jobs` | List jobs (filter / sort / paginate) |
| `GET` | `/jobs/:id` | Job by id |
| `POST` | `/jobs` | Create job |
| `PATCH` | `/jobs/:id` | Partial update |
| `DELETE` | `/jobs/:id` | Delete job |

### Agents

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/agents` | List agents |
| `GET` | `/agents/:id` | Agent by id |

### Customers

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/customers` | List customers |
| `GET` | `/customers/:id` | Customer by id |

### Activities

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/activities` | List activities |
| `GET` | `/activities/:id` | Activity by id |

JSON Server also allows `POST` / `PATCH` / `DELETE` on agents, customers, and activities. The web/mobile product scope primarily mutates **jobs**.

## Query parameters

JSON Server `0.17` supports:

| Param | Example | Notes |
|-------|---------|-------|
| Equality filter | `/jobs?status=pending` | Also `priority`, `agentId`, `customerId`, … |
| Pagination | `/jobs?_page=1&_limit=20` | Use **`_limit`**, not `_per_page` |
| Sort | `/jobs?_sort=dueDate&_order=asc` | |
| Full-text | `/jobs?q=HVAC` | Searches string fields |
| Slice | `/jobs?_start=0&_end=20` | Alternative to page/limit |
| Operators | `/jobs?priority_ne=low` | `_gte`, `_lte`, `_like`, `_ne`, … |

### Examples

```bash
curl "http://localhost:3001/jobs?status=pending&_page=1&_limit=20"
curl "http://localhost:3001/jobs?priority=high&_sort=dueDate&_order=asc"
curl "http://localhost:3001/jobs?agentId=agent-001"
curl "http://localhost:3001/agents/agent-001"
curl "http://localhost:3001/customers?q=Northwind"
curl "http://localhost:3001/activities?jobId=job-00001&_limit=10"
```

Pagination metadata is returned in response headers:

- `X-Total-Count`
- `Link` (when using `_page`)

## Entity shapes

Aligned with `@opsflow/shared` and `docs/PROJECT_SPEC.md` §8.

**Job** — `id`, `title`, `description`, `customerId`, `agentId` (empty string when unassigned), `status`, `priority`, `location`, `createdAt`, `dueDate`, optional `completedAt`

**Agent** — `id`, `name`, `email`, optional `avatar`, `status`, `phone`

**Customer** — `id`, `name`, `email`, `phone`, optional `company`, `location`

**Activity** — `id`, `jobId`, `type`, `description`, `createdAt`, optional `actorId`

Enums:

- Job status: `pending` | `assigned` | `in_progress` | `completed` | `cancelled`
- Job priority: `low` | `medium` | `high` | `critical`
- Agent status: `available` | `busy` | `offline`

## Analytics

There is **no** dedicated `/analytics` aggregation endpoint.

Clients should fetch jobs (and related data as needed) and derive KPIs/charts in the frontend (see `docs/DECISIONS.md` ADR-008).

## Known JSON Server limitations

| Topic | Limitation | POC approach |
|-------|------------|--------------|
| `_per_page` | Spec example used `_per_page`; json-server uses `_limit` | Document and use `_limit` in clients |
| Multi-field OR search | Limited | Prefer `q` or multiple filtered requests |
| Aggregations | None | Client-side derived analytics |
| Auth | None | Out of scope for POC |
| Persistence durability | File watch / in-memory style DX | Fine for demo; not production |
| `null` foreign keys | DELETE can 500 when `agentId` is `null` | Seed uses `""` for unassigned agents (ADR-015) |

## CORS

`json-server` enables CORS by default, so the Next.js app (`localhost:3000`) and React Native clients can call `localhost:3001` during local development.
